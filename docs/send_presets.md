# 常用报文（发送预设）使用指南

「常用报文」是一个独立窗口，用来保存多组发送配置（名称/通道/ID/扩展/帧类型/数据），
方便**快速切换并发送**不同报文，并可**保存/加载**整组配置复用、分享。

> 适用场景：调试时反复要发几条固定报文（如电机使能、模式切换、心跳…），存成预设后
> 一键发送，免去每次手填 ID 和数据。

---

## 打开窗口

1. 启动主界面：`python3 gui/main_gui.py`
2. 在「主发送窗口」区点击 **「常用报文」** 按钮，弹出独立窗口。
3. 窗口可与主界面并排摆放；关闭后再打开，已添加的预设仍在（应用运行期间保留；
   要长期保存请用「保存到文件」）。

> 窗口**不依赖连接**也能打开，可离线编辑、保存、加载预设；发送时才需要对应通道已连接。

---

## 界面与操作

窗口是一个预设表格，列为：**名称 / 通道 / ID (Hex) / 扩展 / 帧类型 / 数据 (Hex) / 操作**，
每行「操作」列有独立的 **发送** 按钮。

| 按钮 | 作用 |
|---|---|
| **行内「发送」** | 按该行配置发送一帧到其指定通道（**快速切换数据的核心**）。 |
| **新增** | 弹出对话框新建一条预设。 |
| **编辑** | 编辑选中行（也可**双击该行**编辑）。 |
| **删除** | 删除选中行。 |
| **填入主发送** | 把选中预设填入主发送窗口，便于在主窗口做**单次/周期/突发**发送。 |
| **保存到文件** | 把当前所有预设导出为 JSON。 |
| **从文件加载** | 从 JSON 载入整组预设（替换当前列表）。 |

### 新增 / 编辑对话框字段

| 字段 | 说明 |
|---|---|
| 名称 | 任意标签，如「电机使能」；留空则自动用 `ID xxx`。 |
| 通道 | 该预设发往的通道号（整数）。下拉会列出当前已连接通道，也可手填。 |
| ID (Hex) | 仲裁 ID，十六进制，如 `200` 或 `18FF50E5`。 |
| 扩展帧 | 勾选=29 位扩展帧，不勾=11 位标准帧。 |
| 帧类型 | CAN / CAN FD / CAN FD+BRS。 |
| 数据 (Hex) | 空格分隔的十六进制字节，如 `01 02 0A FF`。 |

---

## 发送行为说明

- 行内「发送」是**单次发送**到预设里记录的通道。
- 需要**周期/突发**发送时，点「填入主发送」把该预设送回主发送窗口，再用主窗口的
  「周期/突发」功能操作。
- 预设里的通道**未连接**时点发送会提示「通道 N 未连接」，不会崩溃。
- 24 字节等超过 8 字节的数据属于 **CAN FD**，需以 FD 模式连接通道。

---

## 配置文件格式（保存/加载的 JSON）

```jsonc
{
  "version": 1,
  "presets": [
    {
      "name": "电机使能",       // 标签
      "channel": 0,             // 发往通道号
      "id": "200",              // 仲裁 ID（十六进制字符串）
      "is_extended": false,     // 是否扩展帧
      "frame_type": "CAN",      // "CAN" / "CAN FD" / "CAN FD+BRS"
      "data": "01 00"           // 十六进制字节，空格分隔
    },
    {
      "name": "FD大帧",
      "channel": 1,
      "id": "18FF50E5",
      "is_extended": true,
      "frame_type": "CAN FD+BRS",
      "data": "DE AD BE EF 11 22"
    }
  ]
}
```

把这份 JSON 分享给同事，对方「从文件加载」即可获得同一套常用报文，无需写代码。
